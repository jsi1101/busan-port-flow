# 부산항 물류 흐름 안내

부산항 게이트 혼잡으로 발생하는 도심 교통 정체를 줄이기 위한 웹사이트 시제품입니다.

## 실행 방법

`index.html` 파일을 더블 클릭하면 브라우저에서 바로 열립니다.

## 실시간 도로 데이터 연결

1. 국가교통정보센터(ITS) 교통소통정보 API 인증키를 발급받습니다.
2. GitHub 저장소를 Vercel에 연결합니다.
3. Vercel 프로젝트의 `Settings → Environment Variables`에 `ITS_API_KEY`를 추가합니다.
4. 재배포하면 웹사이트는 부산항 주변 도로의 실시간 속도를 매분 불러옵니다.

## 실시간 우회 경로 연결

1. 카카오모빌리티 Developers에서 자동차 길찾기 API의 REST API 키를 발급받습니다.
2. Vercel 환경변수에 `KAKAO_REST_API_KEY`를 추가합니다.
3. 재배포하면 트럭 기사 화면이 출발지부터 세 게이트까지의 이동시간과 게이트 대기시간을 합산해 최적 경로를 추천합니다.

인증키는 `.env`에만 보관하고 GitHub에 올리지 않습니다. `.env.example`은 형식 예시입니다.

## 구성

- 시민 화면: 항만 주변 도로의 혼잡도를 지도와 색상으로 안내
- 트럭 기사 화면: 게이트별 예상 대기시간 및 추천 우회 경로 안내

## 색상 기준

- 빨간색: 혼잡
- 노란색: 주의
- 초록색: 원활

## 휴대폰 앱으로 설치

배포된 사이트를 휴대폰 브라우저로 열면 앱처럼 설치할 수 있습니다.

- Android Chrome: 메뉴 → `앱 설치` 또는 `홈 화면에 추가`
- iPhone Safari: 공유 버튼 → `홈 화면에 추가`

설치 후 앱 아이콘으로 실행되며, 트럭 기사 화면의 `내 위치` 버튼으로 현재 위치를 가져올 수 있습니다.
